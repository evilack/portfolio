Introduction

저는 게임 클라이언트 개발에서 출발해 엔진, 렌더링, 플랫폼, 빌드 환경까지 경험을 넓혀 온 엔진 프로그래머입니다. DirectX 자체 엔진과 Unity3D 프로젝트를 거쳐 Unreal Engine 기반 상용 프로젝트를 다수 경험했으며, 콘텐츠 구현뿐 아니라 엔진 업데이트, 성능 분석, 플랫폼 대응, 개발 파이프라인 개선처럼 프로젝트의 기반을 안정화하는 업무를 꾸준히 맡아 왔습니다.

최근 UE5 프로젝트에서는 엔진 버전 업그레이드, Lumen/SSGI/VSM/Nanite/HLOD 관련 렌더링 프로파일링, World Partition 기반 대규모 월드 로딩, JoltPhysics 충돌 데이터 추출과 검증, 서버/클라이언트 빌드 이슈 대응, DDC·Horde·Jenkins 기반 개발 인프라 개선을 수행했습니다. 문제가 발생했을 때 현상을 재현하고, 프로파일링과 로그를 통해 원인을 분리한 뒤, 팀이 다시 같은 문제에 묶이지 않도록 가이드와 자동화 흐름까지 정리하는 것을 중요하게 생각합니다.

또한 생성형 AI를 Unreal Engine 개발에 실전 적용하기 위해 XAMir 규약을 AI 작업 조건으로 구조화하고, 규약 위반을 줄이는 프로토타입 개발 흐름을 검토했습니다. 앞으로도 엔진 안정성, 렌더링 성능, 대규모 월드 로딩, 빌드/개발 파이프라인의 효율을 높이며 개발팀이 더 빠르고 안정적으로 콘텐츠를 만들 수 있는 환경을 만드는 엔진 프로그래머로 기여하고자 합니다.
